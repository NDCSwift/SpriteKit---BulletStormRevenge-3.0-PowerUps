# 🚀 Bullet Storm Revenge 3.0 — Power-Ups
A SpriteKit shoot-em-up with a full power-up system — shields, rapid fire, and multi-shot upgrades.

---

## 🤔 What this is
This project is version 3.0 of Bullet Storm Revenge, extending the base game with a power-up system built in SpriteKit. It shows how to spawn, collect, and apply power-ups in a real-time arcade game, including timed effects, stacking bonuses, and visual feedback for active upgrades. A hands-on SpriteKit game project from concept to playable build.

## ✅ Why you'd use it
- **Power-up system** — Demonstrates how to implement collectible, timed power-ups in a SpriteKit game loop
- **SpriteKit physics** — Shows collision detection, contact delegates, and node categorization for game objects
- **Game state management** — Covers score tracking, lives, level progression, and game-over handling

## 🚀 Getting Started

### 1. Clone the Repo
```bash
git clone https://github.com/NDCSwift/SpriteKit---BulletStormRevenge-3.0-PowerUps.git
cd SpriteKit---BulletStormRevenge-3.0-PowerUps
```

### 2. Open in Xcode
Double-click `BulletStormRevenge.xcodeproj`.

### 3. Set Your Development Team
In Xcode: **TARGET → Signing & Capabilities → Team** — select your team.

### 4. Update the Bundle Identifier
Change `com.example.MyApp` to a unique reverse-domain ID.

## 🛠️ Notes
- SpriteKit games run in the Simulator but feel best on a real device.
- This is part of an ongoing series — check the channel for earlier versions.
- If you see a code signing error, verify Team and Bundle ID are set.

## 📦 Requirements
- Xcode 15+
- iOS 16+
